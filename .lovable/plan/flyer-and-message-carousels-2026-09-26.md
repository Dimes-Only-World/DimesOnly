# Flyer and message carousels

## What will change
- Show one flyer at a time in a centered carousel, with left/right arrows appearing when a second flyer exists.
- Wrap from the last flyer back to the first, and from the first to the last.
- Keep flyer images fully visible inside a stable display area so logos are not cropped or squeezed.
- Keep each flyer's download, share options, share history, and AI suggestions working.
- Add an admin-managed carousel of ready-to-send messages inside the existing Fliers admin tab.
- Let admins add, edit, reorder, show/hide, and delete messages.
- Show one ready-to-send message at a time on Make Money, with left/right arrows when multiple messages exist.
- Automatically append the viewing member's exact referral URL to every admin-created message, preserving the format `https://DimesOnly.World?ref=username`.

## Data and access
- Add a private admin-managed message collection with message text, display order, and active status.
- Members can receive active messages only through the existing protected Make Money service; direct public table access stays disabled.
- Admin changes continue through the existing verified admin service.

## Verification
- Confirm one flyer has no arrows and two or more flyers loop in both directions.
- Confirm wide and tall flyer artwork remains fully visible.
- Confirm admin message changes appear in the member carousel.
- Confirm every displayed/copied message ends with the signed-in member's referral URL.
